# GHOST//GRID

Тетрис в одном HTML-файле: неоново-киберпанковый стиль (по мотивам Ghost in the Shell и вайба Grimes — Genesis), без установки и зависимостей. Работает на компьютере и телефоне.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | ← → | свайп влево/вправо |
| Поворот | ↑ | тап по экрану |
| Быстрое падение | ↓ (зажать) | медленный свайп вниз |
| Сразу поставить | Пробел (зажать — повторять) | быстрый свайп вниз |
| Ход назад | Z / Backspace | ↶ |
| Пауза / заново | P / Enter | ❚❚ / тап, когда игра на паузе или окончена |

## Особенности

- **Энергия отката.** Ход назад стоит 8 энергии (максимум 16). Очистка линий даёт энергию: 1 линия +1, 2 линии +2, 3 линии +3, 4 линии +8.
- **Вирус.** С 12-й фигуры, а затем каждые 9 фигур блок в стакане заражается. Зараженный ряд не очищается. Каждые 6 фигур вирус перекидывается на соседний блок.
- **Лечение.** Очистка n линий лечит вирус в радиусе n рядов, 4 линии стирают весь вирус.
- Разные анимации очистки: 1 линия — сальто робота, 2 — водный взрыв, 3 — крошение блоков, 4 — взрыв.
- Достижение «Квадро» за 4 линии одним ходом.

Все числа баланса лежат в объекте `CFG` в начале скрипта в `index.html`.

## Запуск

Откройте `index.html` в любом браузере или включите GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
